# 얼굴 사진 파비콘 설계

## 목표

- `/Users/mlv_intern/Documents/samsung/a.jpg`를 브라우저 탭 제목 왼쪽에 표시되는 파비콘으로 사용한다.
- 작은 크기에서도 얼굴이 식별되도록 얼굴 중심 정사각형으로 크롭한다.
- 원본 사진은 변경하지 않고 웹사이트용 파생 이미지만 저장한다.

## 이미지 처리

원본은 3024×4032 JPEG이다. 얼굴, 눈, 코, 입과 주변 머리카락이 함께 보이도록 원본 좌표 기준 `1600×1600`, 시작점 `x=0`, `y=650` 영역을 정사각형으로 자른다. 이 영역을 512×512 PNG로 축소해 `src/assets/favicon.png`에 저장한다. 얼굴 형태나 색상을 생성형 AI로 변경하지 않는다.

## 웹 연결

`src/routes/__root.tsx`에서 생성된 PNG를 Vite asset URL로 가져오고 전역 `<head>` 링크에 `rel="icon"`, `type="image/png"`로 등록한다. 모든 라우트가 같은 루트 head를 사용하므로 메인 화면과 생성 화면 모두 같은 파비콘을 표시한다.

## 검증

- 생성된 PNG가 512×512이며 얼굴 중심 크롭인지 직접 확인한다.
- TypeScript 검사와 프로덕션 빌드를 실행한다.
- Playwright에서 `/create` 문서의 `link[rel="icon"]`이 생성된 PNG asset을 가리키는지 확인한다.
- 기존 영상 생성·재생·다운로드 브라우저 테스트가 계속 통과하는지 확인한다.
